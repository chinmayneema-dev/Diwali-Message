SHUBH DEEPAWALI — TEMPLE GREETING WEBSITE

RUN LOCALLY
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. The supplied Ram Siya Ram flute audio is already included as music.mp3.

CUSTOM MESSAGE
The English greeting supplied by Chinmay Neema is included in index.html.
To edit it, find the JavaScript constant DIWALI_MESSAGE near the bottom of the file.

MUSIC
The background music is the audio file supplied by the user, included as music.mp3.
It loops during the greeting. Visitors can pause or resume it using the music control.
Browsers require a user interaction before audio can play.

PUBLISH ONE SHARED LINK
1. Extract this ZIP.
2. Visit https://app.netlify.com/drop
3. Sign in or create a free Netlify account.
4. Drag and drop the extracted folder (containing index.html and music.mp3).
5. Share the public URL Netlify gives you with all your friends.
Each friend enters their own name on the welcome screen.

NOTES
- This is a static website; it does not collect or store names.
- It is responsive for mobile and desktop.
- Keep index.html and music.mp3 together when uploading/deploying.
