SHUBH DEEPAWALI — TEMPLE GREETING WEBSITE

HOW TO USE OR RUN LOCALLY

1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. The supplied Ram Siya Ram flute audio is already included as music.mp3.

NOTES
- This is a static website; it does not collect or store names.
- It is responsive for mobile and desktop.
